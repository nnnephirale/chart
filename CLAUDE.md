# Astrology charts

Interactive natal-chart pages. The live one is `lu-chart-desktop.html`. `lu-chart.html`, `lu-chart-ios.html` and `lim-chart.html` are older originals; leave them untouched unless asked.

Before any work, read:
- `DESIGN-NOTES.md`: every design and interaction rule the user has set (modes, locking, panel, motion, colour, sign ordering). Add new rules there when the user states them.
- `copy-rewrite/README.md`: writing rules, progress on the copy rewrite, open questions and known data issues.

Writing in short: hobbyist readers, middle-school reading level, talk to "you", mainstream astrology only (no esoteric rays), every draft through the `humanizer` skill, no invented facts. Show before/after samples for approval before changing the site's copy.

Goal: a repeatable process where pasting an astro.com "delineated Walter Pullen" (Astrolog) output produces a chart page that follows these rules. That pipeline isn't built yet; see the README's last section.
